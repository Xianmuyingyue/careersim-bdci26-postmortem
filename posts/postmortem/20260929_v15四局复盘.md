### 判读

1. **两臂统计上完全不可区分**（三个 Fisher 检验全部 p=1.0）。
2. **完赛局均值几乎重合（70.66 vs 70.94）**——这是最有力的证据：只要活到 48 月，两臂的表现没有差别。
3. v15 唯一的「损失」在最高分带：v3_rerun 8 局里 4 局 71+，v15 4 局 0 局 71+。若两臂同分布，P(4 局全 <71) = 0.5⁴ ≈ **6%**——偏低但完全在抽样噪声范围（与 v14 判读时 6% 的先例同量级，当时同样未据此推翻）。
4. v15 的爆雷防御（修正 A）真实有效：0/4 爆雷 vs 基线 37.5%。但爆雷的实际代价有限（v3_rerun 三个爆雷局中两个仍完赛 57–59 分，每次爆雷仅 −5 加权分），所以防爆雷的期望增益 ≈ 37.5% × 5 ≈ **1.9 分**，量级恰与 E[max3] 差值 −2.32 相当——两者基本对冲。

## 三、两局早死根因链（同一模式复现）

### RUN 3（31.63）：M6 差 1 点 → 18 个月恢复失败 → 绩效处决

- **M6 首窗评审**：S9 ✓ / N3 ✓ / **O2（门槛 3，差 1）** → 落榜。
- 根因细节：M4 选「引入新框架」（+3 skill, **−1 output**）、M5 选「按计划健身」（未补 output），进入 M6 时 O=2 已成定局（评审在评审月首回合用即时状态结算）。
- **M7–M11 恢复期净增益 = 0**：M12 快照与 M6 完全相同（S9 N3 O2）。LKP 主行动每季 +2 output，但 L1 CAP=3 零余量 + 剧情持续扣减 ⇒ 每次补到 3 又被扣回 2，**永远追不上**。
- M12/M18 连续落榜（M18 还缺 N）；谈话档位 bad(M6) → average(M12/M18) ；M24 晋升 L2 与「两次绩效不佳」炒鱿鱼**同月发生**。

### RUN 4（19.90）：M6 双缺 + 爆雷 → 绝对防御锁死补量

- **M6 首窗评审**：S7（<8）且 **O0（<3）双缺**，同月 hidden_risk=5 触达爆雷级、谈话 bad 档。
- 爆雷后进入绝对防御（爆雷计数=1），补量让位排雷 ⇒ M12 时 O 仍为 0，第二窗再落榜。
- M18/M24 谈话连续 bad；network 崩至 **0**；M24 被「两次半年绩效不佳」处决，L1 终身未晋升。

### 共同结构：★ L1 落榜后恢复力 = 0（引擎级机制，非 v15 特有）

```
M6 落榜（差 1–3 点）
  ⇒ L1 CAP = 门槛（9/3/3 零余量）+ output/network 是消耗品
  ⇒ 落榜后每季补量增益 ≈ 剧情扣减（净增益 ≈ 0）
  ⇒ L1 锁死 → 谈话档位持续 bad/average + 奖金 C/D
  ⇒ 累计两次绩效不佳 ⇒ M24 炒鱿鱼（绩效线处决，与爆雷无关）
```

v3_rerun 的三个早死局同一模式：30.8（M24 死，1 爆雷）、28.88（M13 财富线死）、57.62（M45 死，1 爆雷）。**此模式对全体臂成立，v15 既没有引起它也没有修复它**——§七 破壁协议给出的 LKP 强制 / L1 豁免解决的是「铁律 1 自锁」，而这两局死于「补量速度 < 消耗速度」，是另一个缺口。
