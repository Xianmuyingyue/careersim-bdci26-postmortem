# 风险控制（Risk Guardian）

## 何时使用

在 `situation-awareness` 之后、`decision-policy` 之前。本技能**只输出约束与建议，不直接做选择**。

## 一、风险为什么最贵

`hidden_risk` 同时打击三条路径：

| 传导 | 后果 |
| --- | --- |
| 风险控制维度（权重 10%，上限 10） | 累计口径直接扣分 |
| 谈话 `talk_score`（每点 **−2.0**） | 足以把 good 档（绩效分 +2）打成 average 档（0） |
| 绩效分 → 奖金档位 → 财富（20%） | A 档 `1.5×月薪` 掉到 B 档 `0.5×月薪` |

**爆雷（`hidden_risk ≥ 5`）代价**：`output` 回写为 6 个月前快照 + `dignity−2` + **`wealth−2`** + 爆雷计数 +1；
爆雷计数在 `talk_score` 中权重 **−4.0**；**第二次爆雷 = 出局**。

## 二、风险读数（唯一数据源：`events` 中的 HR 闲聊）

| 文案 | 表情 | `hidden_risk` | 本技能裁决 |
| --- | --- | --- | --- |
| 最近干得还不错，继续保持～ | 笑着 | 0 | 绿灯：可承受 1 点风险换取 output |
| 近期有点风险，不过问题还不大 | 偷偷 | ≈1 | 黄灯：禁止新增风险 |
| 积攒了不少风险，自己好好处理好 | 皱着眉头 | ≈2–3 | **橙灯：本季必须排「处理历史埋雷」** |
| 你自求多福吧… | 神情复杂 | ≈4 | **红灯：埋雷 + 低调避险，全面防御** |
| 早干啥去了，之前埋的雷全要炸了！ | 生气 | =5 | **已来不及——爆雷当回合或下一回合发生** |

> 该信号**每月刷新一次**，是本局唯一的实时风险读数。**止损点在橙灯与红灯两级。**

## 三、硬约束（违反即改选）

1. **`health` 是唯一的一击必杀变量**（`health ≤ 0` 立即出局，**无任何补救机会**）。**`health ≤ 3` 时禁止一切 `Δhealth < 0` 的选项**；`health ≤ 5` 时每季度必须预留至少 1 点体力给「健康恢复」。
2. **尊严不得连续 3 个月 ≤1**。`dignity ≤ 3` 时禁止再扣尊严。**dignity 每点值 `talk_score +1.0`，满值 10 极易维持，视为不可动资产。**
3. **人脉不得连续 3 个月 ≤1**。`network ≤ 3` 时禁止扣 `Network`。
4. **财富不得连续 3 个月 ≤0**。`wealth ≤ 2` 时优先保证正向现金流。
5. **风险**：橙灯起（≈2–3）本季必排埋雷；红灯起（≈4）禁止一切正风险选项。
6. **绩效不得连续两次 <4**（HP 2）。**谈话滑入 average / bad 档 → 下一季度强制拉起能力与业绩：体力全投「准备汇报材料」与「技能学习」，禁止任何保守/避险类选项。**
7. ★ **配比否决权**：当 `skill > 2 × network` 时，**禁止任何 `ΔSkill > 0` 的选项**，直到配比回到 2:1 以内。
   （实测代价：配比 2.47 的一局，8 次谈话仅 1 次 good，**财富 18.1 对 38.5，直接腰斩**。）
8. **评审月保护**：本月是评审月时，禁止任何扣 `dignity`、增 `hidden_risk`、扣 `health` 的选项。

> 冲突时按「健康 > 尊严 > 人脉 > 风险 > 财富 > 产出」裁决。
> `health` 是**生存变量，不是得分变量**：它不值分（`talk_score` 仅 0.25/点），平时不必堆高；
> 但**归零即终局**，因此 `health ≤ 3` 时其优先级高于一切得分项。
> **实测代价**：一局初始 `health=5`，Agent 连续忽略恢复，第 6 个月归零 →「速通离职」`E` 级，总分 25.84。

## 四、风险治理节律（核心动作）

**不等预警才灭火，改为固定节律预防。**

| 节律 | 动作 |
| --- | --- |
| 每 2 个季度 | 固定排 1 次「处理历史埋雷」（2 体力），把风险长期压在 0–1 |
| 评审窗口前 1 个季度 | **额外**排 1 次埋雷，锁定谈话 good 档 |
| 收到「皱着眉头」 | 当季立即埋雷，不受节律约束 |
| 收到「神情复杂」 | 埋雷 + 主行动改「低调避险」，直到信号回到「笑着」 |
| 收到「生气」 | 已无法挽回，全力保护 `output`（避免再叠加 risk） |

**预算提示**：全局仅 48 点体力。首局只用 4 次埋雷（8 点）却积累 11 次预警——**问题在投入不足**。
建议埋雷预算 **8–10 次（16–20 点，约占 35%–40%）**。

## 五、止血动作库（按性价比）

| 情形 | 首选 | 效果 |
| --- | --- | --- |
| 风险升档 | 体力「处理历史埋雷」 | `HiddenRisk −1`（同时提升 talk_score 2 分） |
| 健康告急 | 体力「健康恢复」 | `Health +2` / 1 体力 |
| 尊严告急 | 体力「心理修复」 | `Dignity +2` / 1 体力 |
| 人脉告急 | 主行动「建立导师关系」/「修复关键关系」 | 每季 1 次 |
| 风险 + 健康双告急 | 主行动「低调避险」 | `Health +1, HiddenRisk −1` |
| 现金流告急 | 争取晋升（提升月薪档位）；避免绩效落到 C/D（负奖金） | 结构性解决 |

> **动作机会成本**：季度主行动共 16 次。`hidden_risk ≥ 2` 时，主行动应让位给「低调避险」。

## 六、输出格式

```
【风险约束】
风险读数：{笑0|偷偷1|皱眉2-3|复杂4|生气5}（依据：{原文短语}）
硬约束：{逐条列出本回合禁止触碰的条件}
否决触发：{是否命中配比否决权 / 评审月保护}
建议补救：{动作 + 体力消耗，无则写"无"}
```
