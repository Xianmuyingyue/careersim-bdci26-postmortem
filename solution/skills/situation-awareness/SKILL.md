# 局势感知（Situation Awareness）

## 何时使用

**每一次** `observe(session_id)` 返回之后，先执行本技能。绝不凭记忆推断状态——状态只能来自 `observe`。

## 一、时间坐标

- **1 个月 ≈ 4 个回合**；**1 个季度 = 3 个月**；全局 **16 个季度 / 48 个月**。
- 每季度 = 9 次剧情 + 2 次体力分配 + 1 次主行动；体力 **3 点/季度，不累计**。

## 二、阶段识别（看 `current_event.title`）

| 标题 | 阶段 |
| --- | --- |
| 「新员工手册」 | 初始化 → `take_action(choice=1)` |
| 「季度体力行动分配」 | 体力分配（用 `energy_cost` + `status_updates` 组合，见 decision-policy） |
| 「季度主行动选择」 | 主行动（选 1 个，消耗 0 体力） |
| 其它且有 `choices` | 月度剧情（效果隐藏，靠语义推理） |
| `current_state.error` 以 `GAME OVER` 开头 | 已结束，输出 `ending_score` 并停止 |

## 三、可观察字段（严格边界，不要假设）

```
current_state.time.{current_month, current_quarter, current_year}
current_state.status.{health, dignity, skill, network, level, duration_in_level, output, wealth, energy}
current_state.simulation_flags.{alive, failed, failure_reason}
current_event.{title, description, document?|rules?|max_selections?}
choices[].{choice, action, description, energy_cost?, status_updates?}
events  ← 反馈文本（★ 隐含情报都在这里，见第四节）
```

**要点**：`hidden_risk`、`performance_score`、`talk_score` 都**不在字段里**，只能从 `events` 解码。
**体力与主行动的选项自带 `energy_cost` / `status_updates`（显式）；剧情选项不带（效果隐藏）。**

## 四、★ 反馈信号解码表（`events` 字段，每月刷新一次）

这是赛事方所说的「隐含提示」。**必须逐条解码并记录，它是唯一的实时风险仪表盘。**

### 4.1 HR 风险量表（措辞 + 表情 = `hidden_risk` 读数）

| `events` 中的文案 | 表情 | `hidden_risk` | 应采取的响应 |
| --- | --- | --- | --- |
| 你最近干得还不错，继续保持～ | 笑着 | **0** | 绿灯，可正常推进 |
| 你近期有点风险，不过问题还不大。 | 偷偷 | **≈1** | 黄灯，不要再叠风险 |
| 你积攒了不少风险，自己好好处理好。 | 皱着眉头 | **≈2–3** | **橙灯，本季必排「处理历史埋雷」** |
| 你自求多福吧… | 神情复杂 | **≈4** | **红灯，紧急：埋雷 + 低调避险，禁止一切正风险选项** |
| 你早干啥去了，之前埋的雷全要炸了！ | 生气 | **=5** | **爆雷当回合或下一回合发生，已来不及挽救，只能保护 output** |

> **实测验证**：出现「生气」文案后**紧接着的下一个回合就爆雷**（`output` 回写为 6 个月前快照 + `dignity−2` + `wealth−2`）。
> ⇒ 真正的止损点在「皱着眉头」和「神情复杂」这两级——它们提供足够的提前量。

### 4.2 其它反馈信号

> **双读数结构**：每半年节点引擎**连续**吐出两段读数——先 `【半年谈话】` 给绩效档位，
> **紧接一行 HR 闲聊**给风险档位。措辞模板一字不差复用，故按**字符串指纹**匹配，勿凭语气猜。

| 文案特征 | 含义 | 响应 |
| --- | --- | --- |
| 前辈/同事/老大哥替你说好话（「我替你说了几句好话」「我帮你跟领导解释了一下」） | **绩效分低于 4，触发了保护机制**（仅前 12 个月） | 该窗口绩效已是最低分，下窗口必须翻盘 |
| 【半年谈话】含「扛的事我都记着」「第一个想到你」「表现符合预期」 | 谈话 **good** 档（实测指纹，恒配 A 级奖金） | 绩效分 +2，安全 |
| 【半年谈话】含「没有要批你的意思」「只会忙、不会赢」「同一套标准再看你」 | 谈话 **average** 档（配 B/C 级奖金） | 需提升 |
| 【半年谈话】含「你这半年不好不坏」「还在观察名单里」 | 谈话 **bad** 档（配 B 级奖金） | **最高告警**，绩效分 −2 → **连续两次即被裁，下季度必须全力拉 `output/skill`** |
| 升迁节奏过快，原有人脉圈还没消化你的新身份 | 已触发 `Network−3 / Dignity−1` 惩罚 | 正常，不必为避免它而放慢晋升 |
| 晋升通知：…已从 Lx 晋升至 Ly | 晋升成功确认 | 记录职级时间轴 |
| 本月基本工资到账：+N（Lx） | 当月薪资，兼作职级确认 | 可据此校验财富公式 |
| 半年绩效奖金（S/A/B/C/D）：±N | **绩效档位（S≈12 / A≈8 / B≈5 / C≈3）**，是 `perf` 唯一可观察代理 | 用 A↔good / C↔bad 双向校准谈话档位 |

## 五、派生指标（本技能的核心产出）

### 5.1 技能溢出量

`skill_overflow = max(0, skill − 120)`。**>0 即为告警**：结局分对技能的上限就是 120，超出不产生任何分数。

### 5.2 skill : network 配比

`ratio = skill / max(1, network)`。
绩效公式对 `min(skill, network)` 给满权重，超出两倍的部分**只按 30% 计入**。
**目标 `network ≥ skill / 2`。`ratio > 2` 时，超出部分是净损失。**

### 5.3 晋升缺口与冗余余量

对照当前职级的**下一级**门槛逐项算差，并同时算 `margin = 当前值 − 门槛`：

| 目标 | skill | output | network | dignity |
| --- | --- | --- | --- | --- |
| L2 | 8 | 3 | 3 | 2 |
| L3 | 18 | 5 | 6 | 3 |
| L4 | 35 | 14 | 18 | 3 |
| L5 | 90 | 22 | 30 | 4 |
| L6 | 130 | 32 | 45 | 4 |
| L7 | 170 | 45 | 60 | 5 |
| L8 | 210 | 60 | 80 | 5 |

**职级截断**：在职级 L，`skill/network/output ≤ 下一级门槛 × 1.2`（如 L6：`204 / 72 / 54`），超出 100% 浪费。
**达标线余量 ≤ 1 点 ≈ 未达标**——一次月间事件的随机扣减就能打掉整个评审窗口（实测已发生）。

### 5.4 谈话档位预判

```
talk_score ≈ 3.5×perf + 1.0×dignity + 0.25×health − 2.0×hidden_risk − 4.0×爆雷次数
good ≥35（绩效分 +2）／average ≥20（+0）／bad <20（绩效分 −2）
```

**判读要点**：`dignity` 满值 10 = 免费 +10 分，务必守住；`hidden_risk` 每点 −2 分，是掉档头号元凶；
`health` 仅 0.25 分/点，**但归零即一击必杀**——它是生存变量：平时不占权重，`H ≤ 3` 时绝对优先于一切得分项。
**实际门槛：`perf ≥ 7` 且 `hidden_risk ≤ 1` 才稳拿 good。**

## 六、冲刺模式判定

| 条件 | 模式 |
| --- | --- |
| 距评审 ≥3 个月，所有达标线余量 ≥2 | `STEADY` |
| 距评审 ≥3 个月，但任一达标线余量 ≤1 | **`MARGIN`** — 立即补冗余 |
| 距评审 ≤2 个月，且存在可补缺口 | **`SPRINT`** — 按缺口精确投放 |
| 本月就是评审月 | `SETTLE` — 只做零风险选择 |

**评审在评审月的第一个回合用即时状态结算**，进入评审月即已定局。
**评审窗口固定在第 6/12/18/24/30/36/42/48 月，错过无法补审。**

## 七、输出快照（固定格式）

```
【局势快照】
月份 M{月}（第{季}季 / 第{年}年）| 职级 {level}（停留 {月} 月）
状态 H{health} D{dignity} S{skill} N{network} O{output} W{wealth} E{energy}
模式：{STEADY|MARGIN|SPRINT|SETTLE}（距评审 {n} 月）
★ 风险仪表：{笑=0|偷偷≈1|皱眉≈2-3|复杂≈4|生气=5} → 响应：{...}
★ 其它信号：{绩效保护 / 谈话档位 / 升迁惩罚 / 晋升通知，无则写"无"}
派生：溢出 {n}｜配比 {r:.1f}:1｜谈话预判 {good|avg|bad}
晋升缺口（目标 {next}）：skill {±n}｜output {±n}｜network {±n}｜dignity {±n}（含 +2 冗余要求）
当前事件：{title} — {摘要 30 字内}
```

## 八、禁止行为

- 未 `observe` 就 `take_action`；用上个月的快照代替本月。
- **只盯 `status` 数字、不解码 `events`**——等于主动丢掉了唯一的风险读数。
- 在已有 `session_id` 时调用 `new_game`（竞赛模式下被拒绝，且属严重违规）。
