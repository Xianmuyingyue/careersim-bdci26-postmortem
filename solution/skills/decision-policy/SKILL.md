# 决策策略（Decision Policy）

## 〇、七条铁律

**每回合输出决策前逐条自检；任一条被破坏都必须改选。优先级高于本文件其余全部内容。**

| # | 铁律 | 实测代价 |
| --- | --- | --- |
| 1 | **维持 `network ≥ skill / 2`**。违反时禁止一切 `ΔSkill > 0` | 配比 2.47 的一局：8 次谈话仅 1 次 good，**财富 18.1 vs 对照 38.5** |
| 2 | **评审月前，每条达标线顶到「阈值 + 2」** | 一局在评审那一刻 `network=17`（门槛 18，**差 1 点**），整级延后 6 个月 |
| 3 | **`skill ≥ 120` 后 `ΔSkill` 记 0 分**，禁用「技能学习」 | 一局 `skill=143`，超上限 23 点全废，且烧掉 22 点体力（占全局 46%） |
| 4 | **16 次主行动默认全投「申请关键项目」** | 一局 5 次分给「申请岗位轮岗」，在 skill 已溢出前提下白扔 `Output +10` |
| 5 | **`hidden_risk ≤ 1`**（谈话 good 档的硬前提） | 每点 `hidden_risk` = `talk_score −2`，直接决定奖金档位 |
| 6 | **`health ≤ 3` 时禁止一切 `Δhealth < 0`**；`health ≤ 5` 时每季留 1 点体力给「健康恢复」 | 一局初始 `health=5` 却连续忽略恢复，第 6 个月归零 → `E` 级「速通离职」，仅 25.84 分 |
| 7 | ★ **季度体力必须 3/3 用尽 —— 做法是"连选 3 次"**：引擎在同一季度会**连续**给出多个「季度体力行动分配」回合，**每回合只能选 1 个行动**，必须一直选到出现非体力回合为止 | 一局每季度只选 1 次就停，24 个月仅用 **9/24** 点体力，`skill` 停在 9 → 绩效连续不合格 → 第 24 月被裁（`E` 级 21.23 分） |

## 一、三个必须记住的事实

**① 财富是职级的影子。** 全事件池 171 个文件中 `wealth` **零命中**——没有任何选项能直接增减财富。
```
财富 ≈ Σ(在职月数 × 职级月薪) + Σ(半年奖金)
月薪：L1 0.3 / L2 0.4 / L3 0.5 / L4 0.7 / L5 1.0 / L6 1.5 / L7 2.3 / L8 3.6 / L9 5.7 / L10 9.1
半年奖金 = 月薪 × 档位系数（S 3.0 / A 1.5 / B 0.5 / C −1.0 / D −2.0）
```
「职级 30% + 财富 20% = 50% 权重」是**同一个变量**。
**⇒ 一切决策的裁判标准：它能否让下一次晋升更早发生？**

**② 评审在评审月的第一个回合用即时状态结算，错过无法补审。**
三次实测失手全是「差 1–4 点」：`skill−2/output−2`、`skill−4`、`network−1`。
**⇒ 达标线余量 ≤1 点 ≈ 未达标**（详见铁律 2）。

**③ 属性有上限，超出即浪费。**
结局分上限：`skill 120 / network 60 / health+dignity 20`；
职级截断：在职级 L，`skill / network / output ≤ 下一级门槛 × 1.2`。

## 二、行动数值表（实测，选项自带 `status_updates` 可直接读取）

### 体力行动（3 点/季度，共 48 点）

| 行动 | 体力 | 效果 | 每点净收益 |
| --- | --- | --- | --- |
| **人脉维护** | 1 | `Network +1, Dignity +1` | Network +1 ← 默认填充 |
| **准备汇报材料** | 1 | `Output +1, Dignity +1` | Output +1 ← 冲刺主力 |
| 健康恢复 | 1 | `Health +2` | `health ≤ 4` 时用 |
| 心理修复 | 1 | `Dignity +2` | `dignity ≤ 6` 时用 |
| 处理历史埋雷 | 2 | `HiddenRisk −1` | 按 risk-guardian 节律 |
| 高强度工作 | 2 | `Output +2, Health −1, Dignity −1, HiddenRisk +1` | 几乎不用 |
| **技能学习** | **2** | **`Skill +1, Health −1`** | **禁用（全池最差）** |

> `Dignity +X` 在 dignity=10 时全额浪费。先看 dignity 再决定是否选带 dignity 加成的动作。
> ★ **体力 3 点/季度，不累计，不用即永久损失。分配方式是「连选 3 次」：**
> 引擎会在同一季度**连着**抛出多个「季度体力行动分配」回合，**每回合只选 1 个行动**。
> 只要标题仍含「体力」，就必须**继续选下去**，直到标题变为非体力回合。
> **在体力回合停下来 = 该季度剩余体力全部作废**——实测最严重失误，一局因此每季只花 1 点，
> `skill` 24 个月停在 9，绩效连续不合格被裁。

### 缺口驱动配方（按冲刺靶心直接查表）

| 缺口 | 配方（3 点） | 产出 |
| --- | --- | --- |
| output 缺 1–3 | `准备汇报材料 ×3` | Output +3 |
| network 缺 1–3 | `人脉维护 ×3` | Network +3 |
| output + network 双缺 | `准备汇报材料 ×2 + 人脉维护 ×1` | Output +2, Network +1 |
| skill 缺 1（唯一例外） | `技能学习 ×1 + 准备汇报材料 ×1` | Skill +1, Output +1 |
| health 告急 | `健康恢复 + 人脉维护 + 准备汇报材料` | Health +2, Network +1, Output +1 |
| 无缺口（STEADY） | `人脉维护 ×2 + 准备汇报材料 ×1` | Network +2, Output +1 |

> 上表 "×N" 表示**连续 N 个回合各选 1 次**该行动（不是一次多选）。
> **`skill` 基本无法靠体力冲刺**（2 体力 = 1 skill），必须在第 12–30 月从剧情选项提前攒足。
> **无缺口时也必须填满 3 点**（默认 `人脉维护 ×2 + 准备汇报材料 ×1`）——华为文化就是榨干最后一点劳动力，
> 闲置体力等于放弃晋升。

### 季度主行动（**消耗 0 体力**，全局 16 次，绝不可选「不行动」）

| 主行动 | 效果 | 选用条件 |
| --- | --- | --- |
| **申请关键项目** | `Output +2, Skill +1, Network +1` | **默认唯一选择**（唯一同时拉满三条硬指标） |
| 建立导师关系 | `Skill +1, Network +2` | network 缺口 > skill 缺口 |
| 申请岗位轮岗 | `Skill +2, Network +1` | 仅当 `skill < 120` 且 skill 为唯一瓶颈 |
| 向领导汇报成果 | `Output +1, Network +1, Dignity +1` | 需补 dignity |
| 低调避险 | `Health +1, HiddenRisk −1` | **风险橙灯/红灯时强制切换** |
| 其它 | 见 `status_updates` | 按缺口 |

## 三、月度剧情选项（效果隐藏，靠语义推理）

```
得分 = 0.35×ΔOutput + 0.30×ΔNetwork + 0.25×ΔSkill
     + 0.15×ΔDignity（已满记 0） + 0.05×ΔHealth（health ≤ 4 时升到 0.40）
     − 0.60×ΔHiddenRisk
```

**硬性修正（必须叠加）：**
1. `skill ≥ 120` → `ΔSkill` 权重 **归零**；
2. `skill > 2 × network` → 禁止 `ΔSkill > 0`（铁律 1）；
3. `skill < 120` 且距门槛有缺口 → `ΔSkill` 权重升到 0.40（skill 无法靠体力补）；
4. **MARGIN/SPRINT 模式下，任何会扣减达标线的选项（`ΔOutput/ΔNetwork/ΔSkill < 0`）一律否决**，即使它带来 dignity 或财富。

**长链事件**要往前多看一步：优先选择能开启正向下游分支的选项。

## 四、冲刺机制（SPRINT / MARGIN）—— 最高回报的动作

| 模式 | 触发 | 动作 |
| --- | --- | --- |
| `MARGIN` | 距评审 ≥3 月，但任一达标线余量 ≤1 | **立即补冗余到「阈值 + 2」** |
| `SPRINT` | 距评审 ≤2 月，且存在可补缺口 | 停止长期最优，按上表配方精确补量 |
| `SETTLE` | 本月即评审月 | 只做零风险选择，保护 dignity / hidden_risk |

**单季度最大补量**：`output +5`（体力 3 + 主行动 2）、`network +4`、`dignity 拉满`、`skill +1`。
**⇒ `output` / `network` 缺口 ≤4 时必须当季顶掉；`skill` 缺口须提前 2–3 个季度布局。**

冲刺季同时执行：主行动必选「申请关键项目」；`hidden_risk` 压到 ≤1（谈话在评审**之前**结算，good 档送绩效分 +2）。

## 五、长期路线（48 个月）

| 阶段 | 目标 | 门槛（skill / output / network / dignity） | 重点 |
| --- | --- | --- | --- |
| 月 1–6 | L1→L2 | 8 / 3 / 3 / 2 | 前 12 个月绩效保底 4，**放心堆 skill 的唯一窗口** |
| 月 7–12 | L2→L3 | 18 / 5 / 6 / 3 | 开始维持 `network ≥ skill / 2` |
| 月 13–18 | L3→L4 | 35 / 14 / 18 / 3 | L3 截断 `skill ≤ 42`，必须尽快晋升解锁 |
| 月 19–30 | L4→L5 | 90 / 22 / 30 / 4 | **最大断层**（skill 35→90）；output 是瓶颈 |
| 月 31–42 | L5→L6 | 130 / 32 / 45 / 4 | skill 逼近 120，**事件权重转向 output** |
| 月 43–48 | L6→L7 | 170 / 45 / 60 / 5 | 冲刺项为 output 与 network；skill 需提前布局 |

**目标基准：`L5 @ 月 30`、`L6 @ 月 42`、`L7 @ 月 48`。**

## 六、晋升节奏：能推就推

同一职级停留满 6 个月即可参加下一次评审。两次晋升间隔 <12 个月触发 `Network−3 / Dignity−1`——
成本约等于一轮 `人脉维护 ×3 + 心理修复 ×1`（4 点体力），远低于提前 6 个月的月薪收益与更高属性上限。
**⇒ 满足门槛即晋升，不为规避惩罚而等待。**（首局月 6/12/18 连续三个窗口晋升，惩罚未阻断晋升。）

## 七、输出格式

```
【决策】
阶段：{剧情|体力|主行动}　模式：{STEADY|MARGIN|SPRINT|SETTLE}
选择：choice={n} {action}
理由：{补齐了哪条缺口 / 规避了哪条红线 / 守住了哪条铁律}
剩余体力：{n}　距评审：{n} 月　待冲缺口：{output ±n / network ±n / skill ±n}
```
