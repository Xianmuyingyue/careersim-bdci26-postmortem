## 🎯 交付件（唯一需要交的东西）

一个 `zip` 包，解包后目录结构必须是：

```
solution/
  manifest.json          # 队名、提交名、运行模式
  README.md
  design/
    skills_design.md     # 技能设计说明（专家评审 30% 的依据）
    decision_report.md   # 决策报告（专家评审依据）
  skills/
    <你的技能1>/SKILL.md  # 必须有 YAML frontmatter 且含 name / description
    <你的技能2>/SKILL.md
```

- 本地校验：`uv run python -m career_sim_runner validate --submission solution`
- 获奖后须开源到 `https://gitcode.com/openJiuwen/agent-store`

## 🧮 成绩怎么算

```
总分 = 云端统一评测 70%  +  专家评审 30%

云端统一评测（70%）= 本地模拟器算出的「量化生存成就 × 0.7」 + 资源效能（Token / 时间）
专家评审（30%）  = 技能设计 · 长期规划 · 框架运用 · 风险控制 · 失败恢复 · 资源优化
```

**量化生存成就（0–100 分）的六个维度：**

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 职级成就 | **30%** | 最终爬到 L 几 |
| 累计财富 | **20%** | 48 个月攒下多少 |
| 身心健康 | 15% | 健康 + 尊严 |
| 专业能力 | 15% | 技能积累 |
| 风险控制 | 10% | 累积风险越低越好 |
| 同事关系 | 10% | 人脉 |

**结局等级：** S ≥ 90 ／ A ≥ 70 ／ B ≥ 60 ／ C ≥ 50 ／ D ≥ 30 ／ E < 30。
**现实目标：** 强 LLM 的现实上限是 **L5–L6**；稳拿 B 以上（≥60 分）即为扎实成绩。

## 🕹️ 玩法闭环（每月 / 每季度 / 每半年）

```
每月：推进月份 → 发月薪 → 生成剧情事件（≤3 个）→ 逐条选择 → 结算
每季度末（3/6/9/12 月）：分配 3 点 Energy（体力行动）+ 选 1 个季度主行动
每半年（6/12/.../48 月）：领导谈话（被动）→ 绩效评估 → 发绩效奖金 → 晋升评审
```

- **剧情选择** = 短期收益与后续分支
- **季度行动** = 主动调节职业轨迹的主要抓手（每季度 3 点体力 + 1 个主行动，共 16 个季度）
- **长线** = 很多风险不会当月爆，攒着以后一起算总账

## 🔌 交互方式（MCP 工具只有 5 个）

| 工具 | 作用 |
| --- | --- |
| `new_game()` | 开新局，返回 `session_id` |
| `observe(session_id)` | 读当前状态 + 当前事件 + 可选项 |
| `take_action(session_id, choice, notes)` | 执行选择，`notes` 写入日志 |
| `show_employee_handbook()` | 读公开手册 |
| `check_latest_logs(session_id, count)` | 读最近日志 |

`make setup` 会自动把 MCP 写进 JiuwenSwarm 实例配置，**不需要手动配**。

## 🚀 最短上手路径（约 60 分钟）

```bash
# 0) 前置：macOS 已具备 git / make / uv / python3（本机已确认可用）
cd "CareerSim-BDCI26"          # 已克隆好的官方仓库

# 1) 装依赖（含 career-emulator 与 jiuwenswarm）
make sync

# 2) 配模型
cp .env.example .env
# 编辑 .env，填 API_BASE / API_KEY，MODEL_NAME 用官方评测模型
make setup

# 3) 起服务（独立终端，保持运行）
make start-jiuwen

# 4) 跑一局
make play

# 5) 看分数 / 看战报
make score
make replay
```

前端 UI：`http://localhost:6173`

## ⚠️ 三个最容易踩的坑

1. **`MODEL_NAME` 写法不一致**：官方文档写 `deepseek-v4.1-flash`，而仓库 `.env.example` 写 `deepseek-v4-flash`。**以文档为准填 `deepseek-v4.1-flash`**，否则本地成绩与云端不可比。
2. **竞赛模式下 `new_game` 只能调用一次**，第二次会直接报错——策略里必须写死"已有 session_id 就绝不重开"。
3. **禁止使用外部数据、禁止小号/串通/抄袭**，违规会被取消成绩并公示。
