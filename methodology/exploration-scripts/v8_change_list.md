## 四、新硬约束：体力零浪费（12 点教训）

**根因定位**（已核对 v7 原文）：decision-policy 决策④「三维 g 全为 0 → `dignity < 10` ? 人脉维护 : **『保留体力』**」——「保留体力」分支直接浪费；且铁律 7 禁止健康恢复兜底后，部分状态（顶格+低风险+满尊严）落入无动作可选的死路，Q7–Q13 累计浪费 12 点。

**改动（落点：decision-policy 决策④）**：

1. **「保留体力 / no_action」从体力行动允许列表中删除**（主行动的「不行动」不受影响——主行动零副作用且有避险用途）。
2. ④ 替换为**零浪费兜底链**（按「仅有收益」排序）：
   ```
   ④ 三维 g 全为 0：
      a. hidden_risk ≥ 1            → 处理历史埋雷（R−1，纯收益）
      b. dignity < 10               → 人脉维护（N+1/D+1，均无副作用）
      c. skill < CAP 且 health ≥ 5  → 技能学习（S+1；health<5 时排除，因 H−1 副作用）
      d. health ≤ 6                 → 健康恢复（铁律 7 上界内）
      e. 以上全不可用               → 人脉维护（N 顶 CAP 时 D+1 仍无害；体力不空转）
   ```
3. **自检**：每季末强制确认「本季体力 3/3 已用尽」；铁律自检行（decision-policy:217）追加「体力 0 剩余」。
4. 与铁律 3「体力连选 3 次」联动：同季多回合体力分配必须连选至用尽，中途不得触发④的终止分支。
