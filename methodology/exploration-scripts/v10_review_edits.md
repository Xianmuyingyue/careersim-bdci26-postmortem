## 硬错误（均已修，附可复现证据）

### E1 · 算术错误：SA 表 L4 行 `stat_term` = 7.20 → 应为 **5.52**

`stat_term = (min(high, low×2) + max(0, high − low×2) × 0.3) / 15`。
L4 满配 `skill=108 / network=36` ⇒ `low=36, high=108` ⇒ `(72 + 36×0.3)/15 = **5.52**`。
`7.20 = 108/15` = **漏乘 0.3**。自证：`7.20 + 2.60 + 0 = 9.80`，与该行自己写的 `perf = 8` 矛盾；
按 5.52 算则 `5.52 + 2.60 = 8.12 → 8` ✓。
其余 7 行的 `stat_term` / `out_term` 逐格手验**全部正确**（`out_term` = 满配 output ÷ 10）。

### E2 · 无法复现的统计量：`r(职级, 档位) = 0.937`，「解释 88% 的档位方差」

- 旧脚本（`perf_census.py`，20 局 / n=118 口径）实测 **0.755**
- 全量脚本（56 局）**原先根本没算这个量** ⇒ 0.937 无出处，疑似把「**按局聚合**」的
  `r(局末职级, 局平均档位) = 0.944` 当成了点级值。**聚合会抹掉局内噪声 ⇒ 两者不可混用。**
- 本次给 `perf_census_all.py` 补了 **§2b 点级相关性与方差分解**，实测：

```
点级 r(职级, 档位) = 0.776（n=377）；仅 M12 起 = 0.688（n=321）
ρ(职级, 档位)      = 0.790
方差分解：职级（组间）解释 71.6%；组内残余 28.4% ← output / 谈话的可动手空间
```

⇒ 真实表述是 **0.776 / 71.6%**，不是 0.937 / 88%。

### E3 · 事实错误：RG「与 36 局通关组不可区分（**它们没有一次 C/D**）」

全量普查的档位轨迹（【10】）显示：

| 组 | M6 档位 | M12 档位 | M18 档位 |
|---|---|---|---|
| 通关（48 月，37 局） | **C×37（100%）** | B×20 **C×17** | B×33 **D×1** C×3 |
| 信任危机end（5 局） | C×5 | B×3 C×2 | B×5 |

⇒ **通关组在 M6 全是 C、M12 还有 17 个 C、M18 还有 1 个 D** ⇒「没有一次 C/D」对两组都不成立。
「独立通道」这个结论**是对的**，但论据要换成可复现的：**组平均档位 2.82 vs 3.02（几乎相同）**，
且 M18–M36 轨迹高度重叠 ⇒ **档位分不开「会被爆雷终结的局」与「通关的局」**。

### E4 · 描述与正文不同源：RG 描述「B2 **三级**响应（≥2 排雷 / ≥3 双清 / ≥4 全禁）」

正文约束 5c 只有两级（`≥3` 排雷+避险 ／ `≥4` 拒收一切 `ΔRisk≥+1`），
且状态行（RG L155 / SA L494）写的也是「≥3 双清 | ≥4 全禁」。
**`description` 是技能的激活键，与正文不同源是硬伤** ⇒ 已把描述对齐为两级。
（若确实想引入「`≥2` 预警级」，必须**同时**改正文，否则描述会指向不存在的动作。）

### E5 · 单一真相源破缺

- **3 处本地脚本路径**（SA L215–216）⇒ 违反本项目「交付物不出现本地文件路径」规则
- 同一批普查数字（366 点 / 6-7 / 3-3 / 40-42 局 / 54-54）**同时出现在 SA §4.3、DP 铁律 18、RG 约束 10**
  ⇒ 这正是历史上「健康恢复门槛同时出现 5 个数字」那类阈值漂移的入口

### E6 · 归因纪律：v9 战绩被三处选择性引用

SA §4.2b②、RG 定位声明、DP §〇 都写「v9 两局 `23.48 / 19.73` 被裁 ⇒ 财富不该追」。
但 **v9 同批 4 局为 `23.48 / 19.73 / 68.06 / 71.78`（2 死 2 通关）**——
**同一套技能下死亡与通关并存** ⇒ 只引死亡局属抽样偏误（`n=4`，费舍尔精确检验 `p≈0.58`，不显著）。
该因果归因**本会话早前已撤回**，此处是它回流到交付物。
（附注：v9 的 4b 是「**防**财富损失」的裁决，把它说成「追财富」本身也不准确。）
