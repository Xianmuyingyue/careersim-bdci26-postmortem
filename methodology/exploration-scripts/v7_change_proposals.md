## 建议一：Plan B（风险约束 5 由 ≤3 放宽到 ≥4）

### 解锁了什么
- 原约束 5：把 `hidden_risk` 控在 ≤3（距爆雷线 5 留 2 点余量），且「文案词典」对**任何 ΔRisk≥+2 的剧情选项永远拒收」。
- Plan B：改为「`当前读数 + ΔRisk ≥ 4` 才拒」（留 1 点余量）。即允许：读数 3 时吃 +1、读数 2 时吃 +2、读数 1 时吃 +3。

### 真实代价与净收益（★ 关键）
- **高 ΔRisk 选项几乎都「捆绑」其它负向**：递归扫描全 291 个含 output/skill 的剧情 choice，凡是带 R+2/+3 的，通常同时带 `Network −2~−3` 或 `Health −3` 或 `Dignity −1`（如「不解释专注出差」O+2/N−3/R+3、「通宵硬修不回滚」O+2/H−3/R+3、「材料对比两人贡献」O+2/N−2/R+1）。
- **真正纯正向的 +2O/+2S 顶级组合**（分阶段交付、ROI 模型等）几乎都带 `R ≤ 0`，**本就能选**，不受约束 5 限制。
- ⇒ Plan B 主要解锁的是「高风险 **且** 别处负向」的选项，**不是**凭空多拿干净收益。净收益是**情境性**的：只有当被扣的维度（N/H/D）早已达标或有缓冲时，这笔交换才划算（如 network 已到 L6 CAP 72、或 health 尚高）。

### 结论
Plan B 收益**有限且条件性**——除非在 N/H 已封顶的局末态，否则放开的选项多为「用风险换别处亏损」。建议若落地，**只放开「+1 风险档」（读数 3 时吃 +1）**，不要放开 +2/+3 的明显亏维选项；把它当作「末段急救」而非全局放宽。

## 建议二：最后大周期激进策略（M48 冲晋升）

### 为什么「最后周期暴雷余量降低」成立
- 首爆**不致死**（risk_burst `hp=2`，二次才 `信任危机end`）；
- 末段几乎没有「未来月份工资」可损失（wealth 联动趋近于 0）；
- 二次爆雷需 `hidden_risk` 从 0 再爬到 5，3 个月内（M45→M48）几乎不可能。
- ⇒ 末段单次爆雷的**有效成本被时间贴现**，这是激进策略成立的前提。

### 可行性（★ 核心，分两步验证）

**时间线**：M48 评审读 `M(6k−1)` 末态 = M47 末；最后能动是 **M45（SPRINT）**；M46/M47 是 GUARD（零行动预算）。爆雷若发生在 M45，其后 M46/M47 无法补救。

**首爆机制回放**：`output → 6 个月前快照(M39)` + `dignity −2` + `wealth −2` + `hidden_risk=0`。
- **关键条件**：若 **M39 时 output/dignity 已 ≥ 门槛**（即提前 6 个月就达标），首爆回写的是「已达标的旧值」，M48 门槛**仍过**。
- 量化（以 L7 门为例，门槛 output≥45 / dignity≥5）：要求 **M39 时 output≥45 且 dignity≥7**（留 −2 余量）；skill≥170、network≥60 不受爆雷影响。
- **唯一真风险**：① output 只在末段（M42 后）才堆到门槛 → 回写跌破；② dignity 没留 ≥7 缓冲 → −2 后 <5；③ 二次爆雷（末段难发生）。

**⇒ 可行性结论**：激进末段策略**可行**，前提是「output/dignity 在 M39 前就提前达标并留缓冲」——而这正是「front-load（前载）」能解决的。它本质是「用首爆的存活余量，换末窗的晋升确定性」。

### 收益
- **L7@M48 vs L6@M48**：职级分 18.0 → 21.0（**+3.0 职级分**）；且 `situation-awareness` 明确「**S 级要求终局 ≥ L7**」——冲到 L7 可能直接把 A 档抬成 S 档（专家评审 30% 权重下是决定性跳档）。
- 末窗是**唯一不能补救**的窗口（M46/M47 无预算），冲 M48 晋升是末段 ROI 最高的一步。
- **一石二鸟**：把 skill 顶到 L6 的 CAP=204（而非刚好 170），还会抬高 perf 门——因为 perf 公式的 `stat_term` 用 skill/network 软帽（`min(high, low×2)+excess×0.3`）：skill 170→200（network 固定 60）时 stat_term 9.0→9.6，perf 门（L7 需 ≥6）更易过。

### 触发条件建议（给「激进」定边界，避免变盲目赌博）
- 进入 **M42 且已 L6** 后激活；目标 L7。
- **M39 前**：output ≥ 门槛（L6 门 32 / L7 门 45）且 **dignity ≥ 7**（爆雷缓冲）。
- `hidden_risk ≤ 3`（首爆后不紧接着二次爆雷）；只吃「负向落在已达标/有缓冲维度」的选项（如 network 已在 60+ 时容忍 N−3，health≥4 时容忍 H−3）。
- 集中在 **M42–M45 的 SPRINT/BUILD**，绝不在 M46/M47（无预算、白搭）。
